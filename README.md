# SwiftDelivery - Courier & Delivery Service Template

A professional, high-end website template for courier and logistics companies.

## Features
- ✅ **Responsive Design**: Mobile-first approach, fully responsive on all devices.
- ✅ **Multi-step Booking**: Intuitive user flow for scheduling deliveries.
- ✅ **Dual Dashboards**: Dedicated interfaces for both Users and Admins.
- ✅ **Dark/Light Mode**: User-controllable theme with system preference detection.
- ✅ **RTL Support**: Built-in support for Right-to-Left languages.
- ✅ **SEO Optimized**: Clean semantic markup with meta tags.
- ✅ **Aesthetic UI**: Minimal, illustration-based design with smooth animations.

## Getting Started
1. Clone or download the repository.
2. Open `pages/index.html` in any modern web browser.
3. Explore the various pages and dashboard functionalities.

## Requirements
- No special requirements. The template uses pure HTML, CSS, and Vanilla JS.
- Internet connection is required to load FontAwesome icons and Google Fonts.
